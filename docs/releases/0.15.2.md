# 0.15.2

Owner release **72**, following 0.15.1 (71).

- **The Daily Planet weather:** VMN now writes the weather section itself, from
  the **Workspace location** only. Each Workspace gets its own place; with no
  location set, the section says so and links to the setting. The assistant's or
  your device's location is never used.
- **Several sources:** Liguria uses ItaliaMeteo ICON-2I, DWD ICON-EU, ECMWF and
  MET Norway with AllertaLiguria and Meteoalarm warnings. Germany uses ICON-D2,
  ICON-EU, ECMWF, DWD MOSMIX and MET Norway with DWD warnings. When models
  disagree, the edition shows a range and says so; days 4–7 are marked as less
  certain, and missing values are never filled in.
- **Weather settings and comparison:** choose sources and weights, the Ligurian
  alert zone and optional learning from DWD stations. Each edition can show a
  compare-sources table and a warnings list. Archived editions keep their forecast.
- **Watchlist:** prices can record shipping and whether VAT is included, and
  offers are compared by delivered total.
- **Header editor:** icon buttons, click to set the focal point, and the
  masthead's shading in the preview.
- **MCP:** new `get_gazette_weather` tool, and `get_gazette_config` now returns the
  Workspace location. No new OAuth scope and no new sign-in: refresh the tool list
  in ChatGPT after deployment. With automatic weather on, the assistant sends only
  the weather summary.

Migration 0081 adds two weather log tables (derived data, pruned after 60 days,
not in portable Workspace backups) and the shipping/VAT columns. Editions written
before this release render as before. No new environment variables.

The server now also contacts `api.brightsky.dev`, `feeds.meteoalarm.org` and
`allertaliguria.regione.liguria.it` (besides Open-Meteo and MET Norway) when a
Daily Planet edition for today or tomorrow is written. If outbound traffic is
filtered, allow these hosts; otherwise the edition names the missing source.

Use `ghcr.io/crimsonclyde/vergissmeinnicht:0.15.2` in Unraid. See the
[Daily Planet user guide](../user/user-guide.md#the-daily-planet) for setup.

Live deployment remains separate.
