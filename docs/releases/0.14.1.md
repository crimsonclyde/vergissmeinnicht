# 0.14.1

Owner release **68**, following 0.14.0 (67).

- **New navigation:** on desktop, a Mac-style menu bar with Dashboard and three
  menus (Plan, Shop & cook, House), with Weather and the time on the right.
  Hover switches between open menus; arrow keys and Escape work too. On phones
  the bottom bar holds Dashboard, your first two tools and **All tools**; tap
  it or swipe the bar up for a drawer with every tool in the same groups. The
  classic sidebar uses the same groups. Every theme has its own touches.
- **Maintenance area:** Equipment and Maintenance share one Maintenance entry
  with tabs, a painted cover with what is due next and warranties ending soon,
  search and chips, and a Cards | List view for Equipment.
- **Contacts and Documents refreshed:** monogram avatars with round call and
  email buttons, category chips; Documents get a folder shelf and page-style
  grid tiles.
- **History and Reminders as a timeline:** finished Runs and Reminders now sit
  on a dated timeline with the same look as Calendar and Notes. Overdue, Today
  and Upcoming are grouped. More and Settings show their entries as tidy icon
  rows, and Storage lists what uses the space. Every theme has its own touches.
- **Recently deleted in Lists:** each List ends with a collapsed "Recently
  deleted" section; one tap puts an item back where it was.
- **ChatGPT can do more:**
  - Groceries: move, delete, edit, tick off and restore items ("I bought
    milk" ticks it off).
  - To-do Lists, Calendar (read the calendar, add one-time reminders) and
    shared Notes (search, read, create, update). Each is a new opt-in
    permission; the private Journal stays out of reach.
  - Recipes: change single fields and archive or restore a Recipe.
  - Clear error messages on every tool, so ChatGPT can say what went wrong.
- **AI connections live in Server admin:** only server admins can allow new
  AI connections now. Existing connections keep working.

Database migrations 0074 and 0075 (grocery list operations) run on start. No
required new environment variable. Existing content is preserved.

Use `ghcr.io/crimsonclyde/vergissmeinnicht:0.14.1` in the Unraid Repository
field. Refresh VMN's connected tools in ChatGPT after deployment; to use
To-do Lists, Calendar or Notes, connect ChatGPT again and allow the new
permissions.

Live deployment remains separate.
