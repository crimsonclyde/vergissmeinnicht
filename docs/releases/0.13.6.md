# 0.13.6

Owner release **61**, following 0.13.5 (60).

- VMN now guides ChatGPT to use the original JPEG or PNG bytes for Recipe photos
  and List covers when ChatGPT can read the file. A directly attached PNG was
  successfully uploaded through the live ChatGPT connection using this route.
- MCP instructions describe how to add, replace and remove Recipe images and
  List covers. A replacement upload must succeed before the old image is changed.
- For a pictured Recipe from a cookbook PDF, ChatGPT must extract the embedded
  photo first. A Recipe that requires a photo is saved only after VMN confirms
  the upload. The end-to-end PDF workflow still needs a hosted test. The
  separate temporary-URL route still rejects the origin observed in testing.

Refresh the VMN tools after upgrading so ChatGPT picks up the new instructions.
[Setup and usage](../admin/mcp.md#upload-an-image-already-available-in-chatgpt)

This patch introduces no database migration. Use
`ghcr.io/crimsonclyde/vergissmeinnicht:0.13.6` in the Unraid Repository field.
