# 0.11.0-beta.0 — A Moment in Time

Owner-counted release **46**, following v0.10.1-beta.0 (45). Release 42 — The Curtain Between Worlds —
and its Halloween dedication remain unchanged.

## Changes

- Celestial always leads Today when personally visible and enabled in the Workspace, ahead of the
  continuation card. Profile → Today explains the defaults and offers independent Celestial,
  Clock and Weather choices. Among these three, only Celestial starts visible. Existing choices remain.
- Clock and Weather open dedicated screens with Back and the shared 48px icon action bar instead of
  overlays. Their contained instruments follow Celestial's navy, gold and readable text styling.
- Clock includes analogue/digital device-local time, date and time zone, Stopwatch with up to 100 laps,
  and Timer with presets and 1–1440 custom minutes. Both timing tools retain independent in-memory state
  during navigation. Pause/Resume and Reset are explicit. Reload/sign-out/close resets them; no sound,
  persisted timing, system notification or reliable background alarm is offered.
- Compact opt-in Clock/Weather tiles work in both Guide and classic layouts. Header, Today and Weather
  screen share a single account/Workspace-scoped forecast. Missing readings, source, fallback, partial-day
  totals and cached freshness remain explicit; existing providers, credentials and server gates apply.
- Updated README features and actual browser screenshots in Space Guide and Memento Mori, with fictional
  studio data and intercepted sample Weather only.

## Upgrade

After publication use `ghcr.io/crimsonclyde/vergissmeinnicht:0.11.0-beta.0` on linux/amd64 or linux/arm64.
This beta publishes only its exact version, never moves `latest`. Verify a full server backup including
original files first; retain the data mount and secrets. No new database migration, dependency,
credential, environment variable or service. The tagged workflow verifies a populated upgrade from the
exact published v0.10.1-beta.0 index. The Unraid template points to this beta; publication is separate
from live deployment.
