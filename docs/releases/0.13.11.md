# 0.13.11

Owner release **65**, following 0.13.10 (64).

- **Weather page:** the opened Weather page uses the painted condition art of
  the Today card. "Now" shows rain chance, wind, feels like, UV index and
  sunrise to sunset, plus gusts and "rain soon" when relevant. Today, Next days
  and Past 14 days are line graphs. No extra provider calls; all themes use
  their own colours.
- **ChatGPT recipe photos in one call:** `create_recipe` and
  `prepare_recipe_meal` take the photo directly, and the new `set_recipe_image`
  adds or replaces the photo of an existing Recipe. Tools ChatGPT cannot use
  are hidden from it. Regional OpenAI file hosts are recognised, a refused host
  is named in the error and log, and `MCP_CHATGPT_FILE_HOSTS` (optional) allows
  extra exact hosts without a release. WebP photos are converted to PNG.
- **Security:** CodeQL code scanning, secret scanning with push protection and
  Dependabot security updates are on. File-name cleanup for downloads and
  Document exports no longer slows down on very long names.
- **Faster checks:** browser tests run in two parallel jobs and a release reuses
  the passing CI of its commit, so PR checks take about 5 minutes instead of 10.

No database migration and no required new environment variable. Existing
content is preserved.

Use `ghcr.io/crimsonclyde/vergissmeinnicht:0.13.11` in the Unraid Repository
field. Refresh VMN's connected tools in ChatGPT after deployment to load the new
recipe-photo tools and instructions.

Live deployment remains separate.
