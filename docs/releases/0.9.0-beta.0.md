# 0.9.0-beta.0 — Release 42: The Curtain Between Worlds

**Halloween, 31 October 2026 · the owner's special 42nd release**

> Dedicated to all the ghosts, extraterrestrials, elder things and lost gods. May we slip through the curtain between worlds, through time, into a great and glorious future.

## What's new

- **The Guide interface:** top navigation across every theme, personal tool shortcuts and a labelled Guide to all enabled tools. Today keeps your cards and choices in one column. Workspace selection, Settings, existing addresses and focused work stay accessible.
- **Galactic Guide:** an optional space theme with floating everyday objects inside translucent cards—a fireplace, a supermarket on a rock, a Tesla coil, a water pump and companions for the existing tools. Decorative objects add no new tools or monitoring.
- **Your appearance:** choose Glass or Starfield, adjust card-background opacity, or turn decorative images off. Text and controls stay readable. Private account settings follow you across devices; existing Places photo/opacity choices and saved theme identifiers are preserved.
- **Less clutter:** personally enabled Clock and Weather move into the top bar. Press for a larger view; weather retains its existing opt-in, location, units, providers and privacy boundaries.
- **A familiar way back:** choose **Profile & settings → Appearance → Existing interface**. Both interfaces use the same data, permissions, history and offline queues. Saved Guide appearance and menu order also survive offline reloads.

## Upgrade

Back up the database **and file storage** before updating. Migration **0060_space_guide** brings the schema to **61 migrations** (0000–0060). On Unraid keep **Migrate on start** enabled. Existing preferences, tool flags, Places settings, records and history remain. Guide is the new default interface; the Galactic Guide theme is opt-in. No new environment variables, services, provider or upload path. Older binaries refuse the upgraded database; rollback requires a compatible build or the pre-upgrade backup.

Image: `ghcr.io/crimsonclyde/vergissmeinnicht:0.9.0-beta.0` for linux/amd64 and linux/arm64. This beta does not move `latest`.
