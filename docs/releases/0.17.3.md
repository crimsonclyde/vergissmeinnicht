# 0.17.3

Owner release **80**, following 0.17.2 (79).

- **Ask VMN:** private native chat from the current page, with streamed answers, Stop, retry and deletion. General questions send no Workspace records. Optional read-only lookups use accessible shared Notes and Recipes and link to verified records.
- **Server admin → AI:** separate Ask VMN and External assistants sections, each with its own configuration and status. Existing ChatGPT grants, consent, file approvals, diagnostics and automatic safety backups remain available.
- **Controlled spending:** a dedicated operator-mounted OpenAI credential, disabled by default, with transactional monthly reservations shared across users and tabs. Failed, cancelled and unknown usage is accounted for conservatively. API usage is billed separately from ChatGPT Plus.
- **Map:** deliberate address-to-pin lookup, full-screen viewing and corrected inland water rendering; Daily Planet rejects invalid precipitation values.

Migration **0086** adds chat settings, opt-in policy, private history and usage; existing MCP grants and Workspace settings remain intact. Native chat does not depend on MCP or the tunnel.
