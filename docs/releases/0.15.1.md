# 0.15.1

Owner release **71**, following 0.15.0 (70).

- **The Daily Planet:** the masthead now uses bundled woodland artwork. Workspace
  admins can upload and crop their own images, fix one image, rotate by edition
  date or publication, and override the image for a published edition. Existing
  editions keep their chosen photo and crop until an explicit override or deletion.
- **Watchlist:** the edition has a product table on desktop and labelled rows on
  phones. Reference prices and verified current offers are separate. Missing offers
  say **Not checked**, and only significant discounts get a highlight.
- **Wishlist:** save an Amazon.de wishlist link in settings and paste reviewed
  reference products into the Watchlist. Reimport matches exact ASINs when available
  and preserves price history. VMN does not automatically retrieve wishlists or prices.
- **MCP:** clients with the existing `gazette.write` grant can create, edit, archive,
  restore and import Watchlist products. Refresh the connected tools after deployment;
  no new OAuth scope is required for a connection that already has write access.

Migrations 0079 and 0080 add product discount overrides and locally stored masthead
images and snapshots. Full server backups preserve custom mastheads; portable
Workspace backups preserve editions and Watchlist data and use bundled masthead art
after restore. No new environment variables.

Use `ghcr.io/crimsonclyde/vergissmeinnicht:0.15.1` in Unraid. See the
[Daily Planet user guide](../user/user-guide.md#the-daily-planet) for setup.

Live deployment remains separate.
