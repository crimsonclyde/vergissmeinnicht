# 0.15.0

Owner release **70**, following 0.14.2 (69).

- **The Daily Planet:** a daily newspaper for each Workspace. Turn it on in
  Plugins. ChatGPT (or any client with the REST API) publishes one edition per
  day with weather, news sections, Good News and your shopping watchlist. The
  Dashboard card shows the headlines and opens the whole paper with one tap;
  the full page has a cover, the last 7 days to flip through and foldable
  sections. An older edition is marked with its date and never shows today's
  weather. Works in every theme.
- **Settings for admins:** name, how many days to keep (7 by default), time
  zone, Dashboard headlines and the sections themselves (show, hide, reorder,
  rename, icon, language, add, remove).
- **Shopping watchlist:** a lasting list of things to watch with a price
  history. Everyone can read it; editors add, archive and record prices. It is
  kept in the Workspace backup and never removed by the daily clean-up.
- **ChatGPT and MCP:** new opt-in scopes `gazette.read` and `gazette.write`
  with six tools to read the setup, publish an edition and update watchlist
  prices. Publishing is safe to retry, and a broken edition never replaces a
  good one. See `docs/development/gazette-api.md`.

Database migrations 0077 (The Daily Planet: settings, editions) and 0078
(watchlist) run on start. No required new environment variable. Existing
content is preserved.

Use `ghcr.io/crimsonclyde/vergissmeinnicht:0.15.0` in the Unraid Repository
field. Refresh VMN's connected tools in ChatGPT after deployment and allow the
new Daily Planet scopes if ChatGPT should publish editions.

Live deployment remains separate.
