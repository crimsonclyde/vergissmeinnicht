# 0.16.1

Owner release **76**, following 0.16.0 (75).

- Download and update regional maps directly in **Server admin → Map data**. Triora, Italy, with a 100 km radius is preselected; search for another town and choose a radius when needed.
- Map data and town/road labels install on the existing data volume. No additional container mount or environment variable is needed. Existing manually installed maps keep working until a managed map is installed.
- Downloads run in the background with progress and cancellation. An update replaces the active map only after the new data is ready; failures leave the existing map available.
- Server-admin access, fixed provider endpoints, strict geographic and download limits, versioned byte-range serving and bounded worker processing protect this new download path. Saved places and private visits are never sent to the map providers.

Allow at least **3.2 GB free** before downloading. Regional map payloads are capped at 1 GB;
choose a smaller area if a dense region exceeds the limit. A server restart stops an unfinished
download, which can be started again. Reopen Map after installing or updating its data.
Town search uses Open-Meteo; map data and fonts come from Protomaps. Updates run only when requested.

No new database migration is introduced; the schema remains at migration **0082**.
The container image is `ghcr.io/crimsonclyde/vergissmeinnicht:0.16.1`.
Managed map data is outside Workspace backups and can be downloaded again.
Live deployment is separate from this release.
