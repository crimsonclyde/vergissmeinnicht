# 0.13.2

Owner release **57**, following 0.13.1 (56).

- The Recipes overview is a responsive visual cookbook with cover thumbnails, preparation and
  cooking times, servings and tags. Editors can add multiple photos and choose a cover.
- VMN MCP accepts original JPEG and PNG bytes from clients with Recipe write access. The
  ChatGPT upload widget lets you select a downloaded generated photo from inside the chat.
  Existing attachment limits and original downloads apply, and retrying the same upload
  returns its existing reference.
- Existing recipes show their first local photo or an illustrated placeholder. Workspace
  backup and restore carry the selected cover with the original image.

The upgrade adds a small runtime table for upload retry receipts. The ChatGPT-hosted widget
and the live Casa Nostra recipe still require verification with the original generated file.
