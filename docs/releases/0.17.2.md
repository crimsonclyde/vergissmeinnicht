# 0.17.2

Owner release **79**, following 0.17.1 (78).

- **AI assistants can now do everything, with a safety backup first.** Before any change made through the MCP connection, VMN writes a full server backup (`vergissmeinnicht-ai-<time>.sqlite` in `/data/backups`), at most every 30 minutes (`MCP_BACKUP_INTERVAL_MINUTES`), keeping the last 48 (`MCP_BACKUP_KEEP`). If the backup fails, the change is refused. The backups are listed in Server admin → AI connections → Safety backups.
- **120 MCP tools.** New scopes for Home (Equipment and Maintenance), Contacts and Documents; Contacts and Documents count as sensitive and are not preselected. Moon, Gamification and Bring stay out of reach for AI.
- **Every app works without a connection.** The whole app is kept on the device, every tool keeps a saved copy of what it last showed, and pictures already seen stay visible. Shared Notes can be written and edited offline, and Reminders can be marked Done; both are sent when the connection is back. An icon shows when you are offline.
- **New Home Screen icon on iPhone**, named "VMN".
- The personal Journal stays online-only: private entries are never kept on the device.

No new migration (schema stays 0085).
The container image is `ghcr.io/crimsonclyde/vergissmeinnicht:0.17.2`.
Live deployment is separate from this release.
