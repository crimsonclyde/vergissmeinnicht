# 0.11.3

Owner-counted release **48**, following published v0.11.2 (47). Release 42 — The Curtain Between
Worlds — and its Halloween dedication remain unchanged.

## Changes

- **Weather history.** The server keeps the daily minimum and maximum temperature for each place over
  the last 14 local days. A day is recorded only from a fresh forecast fetch; cached or stale copies add
  nothing, so reloading never inflates a day. Each person reads only their own history, and Workspace
  backups leave it out.
- **Weather page rebuilt.** The current reading is at the top, a 14-day temperature graph in the middle
  and the next three days below. Attribution and the fetch time moved to Forecast & weather settings.
  The fallback provider note still appears on the page when a fallback answered.
- **Icon and rain instead of condition text.** The Weather page and the Today card show a condition
  icon with the rain chance, or the rain amount where a provider gives no chance. The condition word
  stays available to screen readers.
- **Today card without its gradient.** The colour fade on the Today card is removed in every theme.
- **Sky animation.** Each condition has its own CSS sky animation on the Weather page and Today card.
  It stops under the system's reduced-motion setting.

## Upgrade

After publication use `ghcr.io/crimsonclyde/vergissmeinnicht:0.11.3` on linux/amd64 or linux/arm64.
This release adds one database migration, `0068_weather_history`, which creates the `weather_history`
table. It starts empty on upgrade and fills in from the next fresh forecast fetch for each place.
Verify a full server backup including original files first; retain the data mount and secrets. No new
dependency, credential, service, environment variable or outbound host. The Unraid template points to
this release.

The release workflow publishes stable tags as `0.11.3`, `0.11` and `latest`. Publication remains
separate from live deployment.

## Known limits

- The 14-day graph starts empty after upgrade and fills one day at a time from fresh fetches.
- If the history database read fails, the forecast request fails too. The history read is not guarded.
- The rebuilt page, the Today card and the sky animations were checked on screenshots only, at 1280 and
  375 px in light and dark. Physical phones and real screen readers have not been tested.
- The Today card's text contrast over its picture was checked visually, not by an automated test.
