# 0.13.12

Owner release **66**, following 0.13.11 (65).

- **Recipe categories and filters:** Recipes can have several categories from a
  fixed list (Starter, Soup, Salad, Main course, Side dish, Dessert, Baking,
  Breakfast, Snack, Sauce & dip, Drink, Cocktail). A filter bar above the
  Recipes adds search, sort (Newest, Recently changed, A–Z), category chips and
  a switch between cards and a compact list. The view choice is remembered per
  device. The list now shows newest first; "Recently changed" gives the old
  order. Markdown and JSON-LD exports include categories.
- **ChatGPT / MCP:** Recipe tools read, set, filter and sort by categories, and
  the assistant is told to set categories on every new Recipe.
- **Weather:** the small readings sit in one centred row across the whole "now"
  card. Next days shows the full week after today; when the chosen forecast
  model is shorter, the remaining days come from the Automatic blend and are
  drawn dashed.
- **Clock page:** the opened Clock shows the painted pocket watch from the Today
  card with live hands, the big time, readings (UTC offset, week,
  sunrise/sunset) and the day as a sky strip. Stopwatch and Timer use the same
  watch with a gold ring.
- **Security:** a CodeQL finding in the Knot link check is fixed.

No database migration and no required new environment variable. Existing
Recipes stay valid; categories are optional.

Use `ghcr.io/crimsonclyde/vergissmeinnicht:0.13.12` in the Unraid Repository
field. Refresh VMN's connected tools in ChatGPT after deployment to load the
category support.

Live deployment remains separate.
