# 0.11.4

Owner-counted release **49**, following published v0.11.3 (48). Release 42 — The Curtain Between
Worlds — and its Halloween dedication remain unchanged.

## Changes

- **Interface settings are per Workspace.** The Guide layout (top bar or sidebar), card style, card
  opacity and card images now belong to each Workspace. They moved from account Appearance to a new
  **Look and layout** page for that Workspace, at `/w/:id/look`, with four tabs: Background, Theme,
  Weather and Navigation.
- **Account Appearance simplified.** "Interface and cards" is removed from account Appearance. Theme
  choice links to each Workspace's Look page. Clock, time format and other personal settings stay
  account-level.
- **Workspace backups.** Per-person Workspace Look rows are left out of Workspace backups and kept in
  full server backups.
- **Offline first paint.** A Workspace's Look shows the default until the server answers. Before, the
  device kept a copy of the account setting.

## Upgrade

After publication use `ghcr.io/crimsonclyde/vergissmeinnicht:0.11.4` on linux/amd64 or linux/arm64.

This release adds one database migration, `0069_workspace_guide`. It adds a validated, nullable
`guide` JSON column to `user_workspace_preferences` and removes `guide` from `user_preferences`.

- Each person's account Look value is copied to every Workspace they are a member of.
- A person who is not a member of any Workspace loses the account value. The default applies.
- Outsiders' rows are untouched.

Verify a full server backup including original files first; retain the data mount and secrets. No new
dependency, credential, service, environment variable or outbound host. The Unraid template points to
this release.

The release workflow publishes stable tags as `0.11.4`, `0.11` and `latest`. Publication remains
separate from live deployment.

## Known limits

- The Clock and Weather artwork backdrop is **not changed** in this release. The artwork file is opaque
  and its navy backdrop is baked in. A transparent asset is needed first.
- Offline, a Workspace's Look shows the default until the server answers. This is a first-paint change
  from the old device copy.
- The Weather tab embeds the existing Forecast & weather settings unchanged. That list shows all of
  the person's Workspaces, not only the one open.
- The new Look page was checked by the Playwright suite at desktop and phone widths. Physical phones and
  real screen readers have not been tested.
