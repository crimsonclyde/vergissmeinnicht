# 0.11.2

Owner-counted release **47**, following published v0.11.0-beta.1 (46). Release 42 — The Curtain Between
Worlds — and its Halloween dedication remain unchanged.

## Changes

- **Weather per Workspace.** The single global "use the Workspace's location" switch is replaced by one
  opt-in per Workspace. Weather settings lists each Workspace as a card; the selected card has one tick
  that saves at once and is disabled when that Workspace has no shared location. Existing consent is
  carried over to every current membership. Other members keep their own choice.
- **Workspace-first theme picker.** Account → Appearance lists each Workspace as a card with its own theme
  options and a default star. The global theme picker appears only while the account has no Workspaces.
  A Workspace without its own theme shows the account theme.
- **Celestial frame.** The older extra frame around the Celestial tile is removed. The illustrated tile has
  one edge, so desktop and phone layouts line up.
- **More Galactic Guide card backgrounds.** Forest, Water and Hearth join Glass and Starfield. Forest, Water
  and Hearth use bundled artwork; Glass stays plain. Card content stays on translucent layers under image
  styles, so text and controls remain readable.

## Upgrade

After publication use `ghcr.io/crimsonclyde/vergissmeinnicht:0.11.2` on linux/amd64 or linux/arm64.
This release adds two database migrations (`0066_workspace_weather_opt_in`, which replaces the global
weather switch with per-Workspace opt-ins, and `0067_guide_card_art`, which limits the Guide card style to
its five values). Verify a full server backup including original files first; retain the data mount and
secrets. Existing weather consent is copied to each current Workspace membership during migration. No new
dependency, credential, service or environment variable. The Unraid template points to this release.
Publication remains separate from live deployment.

The release workflow publishes stable tags as `0.11.2`, `0.11` and `latest`, unlike the beta releases,
which move no tag other than their exact version.

## Known limits

- With Workspaces present, the account default theme cannot be changed in the UI; it remains the fallback.
- A Workspace's theme cannot be cleared back to the account theme in the UI, although the API accepts it.
- Card-art readability was checked on screenshots only; the automated contrast test covers colour tokens,
  not images.
- Physical phones and keyboards, and real screen readers, have not been tested.
