# 0.13.8

Owner release **63**, following 0.13.7 (62).

- Recipe amounts support phrases such as “etwas”, “eine Prise”, “nach
  Geschmack”, “a pinch”, “to taste”, “un pizzico” and “q.b.”. The recipe
  displays the amount before the ingredient and keeps the phrase when servings change.
- ChatGPT's VMN tools now explain how to keep these phrases in the amount
  field. Cookbook imports also get specific guidance for a rejected source,
  amount or cover reference.
- The shopping preview shows descriptive amounts. Shopping Lists use numeric
  quantities, so the quantity defaults to blank for these items.

This patch introduces no database migration. A backup containing the new
amount phrases requires 0.13.8 or later to restore.

Use `ghcr.io/crimsonclyde/vergissmeinnicht:0.13.8` in the Unraid Repository
field. Refresh the VMN tools in ChatGPT after deploying the new image.

The signed image is available for Linux amd64 and arm64. Upgrade
verification passed with ten populated predecessor images, including 0.13.7.
