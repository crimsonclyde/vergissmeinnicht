# 0.13.3

Owner release **58**, following 0.13.2 (57).

- **Shopping and To-do Lists.** New Lists can track purchases or simple tasks. To-do Lists
  have title-only entry, a progress count and a collapsed Done section. Both kinds use shared
  editing and offline sync. Existing Lists keep their Shopping behavior.
- **A clearer Lists overview.** Search by name, filter by type and see progress on compact
  cards. List editors can select one of eight icons or upload a JPEG or PNG cover. The original
  can be downloaded, and Workspace backups preserve it.
- **MCP List covers.** Clients with the separate **List cover images** permission can upload,
  replace or remove covers for Shopping and To-do Lists. Reconnect the client after upgrading
  to grant that permission. The API has been verified locally. Hosted ChatGPT picker support
  still needs live verification.
- **A shared cookbook.** New Recipes made in the web app are visible through Workspaces that
  have Recipes enabled. Choose **Private to this Workspace** to restrict a Recipe to its home.
  Existing Recipes and Recipes created through MCP start Workspace-only. Cards show visibility
  and the home Workspace name. The home Workspace still controls editing.

The upgrade applies migrations 0071 and 0072 for List types, icons and cover references.
It keeps existing Shopping data and supports earlier Workspace backup packages. The shared
image store keeps original bytes and metadata and accounts for previews separately.

Use `ghcr.io/crimsonclyde/vergissmeinnicht:0.13.3` in the Unraid Repository field after
publication.
