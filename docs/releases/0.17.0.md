# 0.17.0

Owner release **77**, following 0.16.1 (76).

- **The theme decides the navigation.** Tokyo Nights and Galactic Guide always use the top menu bar: the name opens the Dashboard, then the Workspace drop-down, Dashboard, News, one **All tools** drop-down, weather, time, the round **+** and your profile picture. Light, Memento Mori, Witch Forest and Places keep the sidebar. The settings button shows your profile picture (or initials) instead of a cogwheel.
- The day ring on the Dashboard opens what it counts. With The Daily Planet on, the weather tile and the top bar show the published edition's weather first.
- The "All / Mine / Shared" filter in the top bar is a per-person setting and starts hidden.
- **A Settings theme.** Every Settings page now has its own quiet theme, whatever theme you picked. It looks as before and keeps your top bar.
- **AI assistants allowed** per Workspace in **Workspace settings → Plugins** (on by default). Switched off, ChatGPT and other assistants can no longer read or change that Workspace.
- Under the hood: one tool gate with a proof that every switched-off tool answers 404, one outbound HTTP client for weather, Telegram and map downloads, theme and tool ids in lookup tables, shared surface tokens for all themes, and tool manifests with Equipment as the first module.

Migrations **0083–0085** apply on upgrade (Guide preference triggers, the AI assistants switch, theme and tool lookup tables).
The container image is `ghcr.io/crimsonclyde/vergissmeinnicht:0.17.0`.
Live deployment is separate from this release.
