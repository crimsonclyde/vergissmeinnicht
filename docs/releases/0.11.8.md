# 0.11.8

Owner-counted release **53**, following 0.11.7 (52). Release 42 — The Curtain Between Worlds —
and its Halloween dedication remain unchanged.

## Changes

- Matching transparent artwork for **fog, cloudy, partly cloudy and sleet** completes coverage of
  every known weather condition. Drizzle and showers share the existing rain painting; sleet now
  shows both rain and snow. The illustrations retain the existing celestial style and card opacity.
- Unknown or unavailable conditions keep a neutral symbol. If a Weather image fails to load, its
  condition symbol appears instead, with the real reading and navigation still available.
- Fixed the tiny fallback symbol: its actual SVG now scales and centers within the illustration frame.
- Updated Debian APT and its library to at least 2.6.2 for CVE-2026-109518. Build and runtime stages
  share the patched base; Debian repository transport uses HTTPS, including the initial patch download.

## Upgrade

After publication, use `ghcr.io/crimsonclyde/vergissmeinnicht:0.11.8` on linux/amd64 or linux/arm64.
The Unraid template points to this version. Verify a full server backup, including original files,
and retain the data mount and secrets before upgrading. Stable publication moves `0.11` and `latest`.

No migration, JavaScript dependency, environment variable, provider, credential, permission or new runtime network
destination is added. Existing preferences and Workspace data remain intact. Live deployment is separate.

## Validation

Local unit/contrast checks and desktop/phone browser flows verify all canonical conditions, actual
image decoding, responsive symbol sizing and a deliberately failed image request. Full release gates
cover lint/typecheck/audit, unit/security tests, browser scenarios, both native image builds/smoke/scans,
keyless signing, CycloneDX SBOM and exact-image verification. Populated upgrades cover independently
verified 0.11.7 and the retained older predecessors. Final results are recorded in the development ledger.

## Known limits

- The forecast contract has no day/night flag; paintings represent the reported condition.
- Physical phones and real screen readers are not covered by local Chromium validation.
- Existing build chunk-size warnings and arbitrary-photo readability limits remain.
