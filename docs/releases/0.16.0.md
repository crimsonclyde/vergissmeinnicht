# 0.16.0

Owner release **75**, following 0.15.4 (74).

- Marauder’s Map is an optional Workspace tool. Enable **Map** in **Workspace settings → Plugins** to collect places, find them on the map or list, and save directions to a destination, parking spot, or trailhead.
- Editors can add local covers, reuse points and walking approaches, and save unresolved links for later. Workspace tags support search and filtering. The coordinate sheet copies labelled WGS 84 pairs for Garmin and other devices.
- Visits, ratings, notes and visit photos are personal. Portable Workspace backups include shared Map records and cover originals. Delegated Map scopes offer shared place search, import preview, batch saves, and revision-checked updates.
- The list works without a basemap. Install a regional PMTiles archive with `MAP_ASSETS_PATH` to enable the interactive basemap.

Migration **0082** applies on upgrade. Map starts off in new and existing Workspaces.
The container image is `ghcr.io/crimsonclyde/vergissmeinnicht:0.16.0`.
