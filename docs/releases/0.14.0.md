# 0.14.0

Owner release **67**, following 0.13.12 (66).

- **Notes and Journal:** a new library with live search, notebook and tag
  chips, cards or a list (cover image, preview, checklist progress) and pinned
  notes at the top. A note now opens as a page to read, with an outline and
  history; the pencil opens a one-screen editor with details beside the text.
  The private Journal gets a month timeline with a small calendar, a writing
  streak, "On this day" and a one-tap "Today's page", plus an optional weather
  and moon line. **Markdown import** sits next to export: up to 50 `.md` files
  at once, and exported files import back unchanged. Every theme has its own
  touches.
- **Calendar in Apple and Google Calendar:** each person can create a private
  subscription link for a Workspace calendar (only their own entries, or all)
  and add it in Apple Calendar, Google Calendar or any calendar app. The link
  can be switched off or replaced at any time. Calendar apps only read it;
  nothing is imported into VMN.
- **Refreshed Calendar:** a new month view with week numbers, today as a filled
  circle, the chosen day in a side panel on wide screens, a month summary
  (open, overdue, done), icon buttons for Month/Agenda and filters, and a
  single month with status dots on phones. Every theme has its own touches.
- **ChatGPT recipe photos:** VMN no longer creates pictures itself. ChatGPT
  makes the image, uploads it and then creates the Recipe. The old image
  settings (`OPENAI_RECIPE_IMAGE_KEY`, `RECIPE_IMAGE_*`) are ignored and can be
  removed from the container.

Database migration 0073 (calendar subscription links) runs on start. No
required new environment variable. Existing content is preserved.

Use `ghcr.io/crimsonclyde/vergissmeinnicht:0.14.0` in the Unraid Repository
field. Refresh VMN's connected tools in ChatGPT after deployment. Google
Calendar only refreshes a subscription every few hours and needs VMN to be
reachable from the internet.

Live deployment remains separate.
