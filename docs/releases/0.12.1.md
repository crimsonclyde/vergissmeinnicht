# 0.12.1

Release authorized; validation in progress. **Not yet published or deployed**. Planned owner release **55**, following 0.12.0 (54).
The published count remains 54. Release 42 — The Curtain Between Worlds — and its dedication remain.

## Changes

- Both `/.well-known/oauth-authorization-server` and its trailing-slash variant return identical
  200 JSON. The same fix covers `/.well-known/oauth-protected-resource/mcp` and its slash variant.
- Unknown discovery paths return 404 JSON instead of the SPA's 200 HTML, also when MCP is disabled.
- Added production-style static-web regression coverage for status, content type, metadata equality,
  query strings, HTML Accept headers, disabled/unknown discovery and ordinary SPA navigation.
- Reviewed `/register` against the RFC 7591 public-client profile and strengthened response assertions.
  Explicit `token_endpoint_auth_method: "none"` and all existing validation remain required.

Exact metadata route matching caused slash requests to miss OAuth handlers and enter the SPA fallback.
No issuer, authorization, token or registration URL changes; no resource/grant migration, dependency,
configuration, permission or public access requirement. PKCE, consent/MFA and Workspace gates remain.

## Validation

**6 targeted files / 88 tests pass**, including OAuth, MCP, MFA, logging, app routing and hardening.
The new regression tests reproduced the HTML responses before the fix. Lint, full typechecks,
production build and diff checks pass; the existing build chunk warning remains.
All **212 unit/security files / 1,652 tests** are verified across the full local run and the
permission-corrected rerun of four sandbox-blocked socket/CLI files. Browser suite, native container
builds/scans, signatures and image checks remain in progress or release-CI work. Hosted ChatGPT tunnel interoperability and live deployment remain untested and separate.
