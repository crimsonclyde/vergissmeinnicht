# 0.11.5

Owner-counted release **50**, following published v0.11.4 (49). Release 42 — The Curtain Between
Worlds — and its Halloween dedication remain unchanged.

## Changes

- **Guide layout and card settings are managed in your profile.** Profile → Appearance → **Interface and
  cards** holds the Guide layout (top bar or sidebar), card style, card opacity and card images. A
  Workspace picker chooses which Workspace's look you are editing.
- **Each look is still per Workspace and per person.** A setting you save applies to that Workspace for
  you only. Other members keep their own settings. Storage is unchanged from 0.11.4.
- **Look and layout page simplified.** `/w/:id/look` now has two tabs, Theme and Weather. The Background
  and Navigation tabs are removed. Their controls are in the profile.

## Upgrade

After publication use `ghcr.io/crimsonclyde/vergissmeinnicht:0.11.5` on linux/amd64 or linux/arm64.

This release adds **no database migration**. No new dependency, credential, service, environment
variable or outbound host. The Unraid template points to this release.

Verify a full server backup including original files first; retain the data mount and secrets.

The release workflow publishes stable tags as `0.11.5`, `0.11` and `latest`. Publication remains
separate from live deployment.

## Known limits

- A Workspace with no saved look shows the default. With three or more Workspaces they look the same
  until each person sets them. Automatic variety between Workspaces is not in this release.
- The Clock and Weather artwork backdrop is **not changed**. The artwork file is opaque and its navy
  backdrop is baked in. A transparent asset is needed first.
- Offline, a Workspace's look shows the default until the server answers.
- The Weather tab embeds the existing Forecast & weather settings unchanged. That list shows all of the
  person's Workspaces, not only the one open.
- Playwright covers the profile and Look pages at desktop and phone widths. Physical phones and real
  screen readers have not been tested.
