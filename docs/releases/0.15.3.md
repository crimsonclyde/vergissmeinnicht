# 0.15.3

Owner release **73**, following 0.15.2 (72).

- **The Daily Planet** has a dated newspaper masthead, a Newsflash for the day's
  summary, and bundled city, coastal and orbital artwork. The masthead follows
  the selected theme when an edition has no saved Workspace image.
- **News** opens the edition directly from the desktop top bar. Click or tap a
  story card to open its original article. Advisory links remain separately usable.
- **Weather** has a labeled temperature chart, visible gaps for missing readings,
  forecast rows on phones, and expandable model and provider details. The forecast
  still uses the Workspace location and preserves model ranges, uncertainty and
  source information when available.
- **Local alerts & road closures** shows official weather warnings above the
  forecast. The edition publisher can add verified civil protection notices and
  major closures, with their source and check time. These are dated edition
  snapshots. Official sources carry subsequent updates.

There are no new database migrations, environment variables, or MCP permission
scopes. Use `ghcr.io/crimsonclyde/vergissmeinnicht:0.15.3` in Unraid.

Live deployment remains separate.
