# 0.13.7

Owner release **62**, following 0.13.6 (61).

- ChatGPT's native file upload for Recipe photos and List covers now accepts
  signed links from the exact Azure Blob storage account observed in the live
  cookbook test. VMN also supports the original OpenAI file host.
- The live ChatGPT connection uploaded the original JPEG extracted from a
  cookbook PDF. The upload returned an attachment reference ready to use as a
  Recipe cover.
- VMN restricts downloads to reviewed HTTPS hosts, verifies the TLS certificate
  against the selected host and validates the downloaded image. A renewed
  signature can reuse the existing upload receipt for the same file.

This patch introduces no database migration. Use
`ghcr.io/crimsonclyde/vergissmeinnicht:0.13.7` in the Unraid Repository field.
