# 0.11.6

Owner-counted release **51**, following published v0.11.5 (50). Release 42 — The Curtain Between
Worlds — and its Halloween dedication remain unchanged.

## Changes

- **Redesigned top bar for the Guide layout.** The bar holds the brand, the Workspace picker, the
  Dashboard scope (All, Mine, Shared), the Dashboard, Procedures, Lists and Guide tabs, an Add (+)
  button, the time when the Clock card is on, and settings.
- **Weather is no longer in the top bar.** It stays on the Dashboard card and on the Weather page.
- **"Today" is now "Dashboard".** The page is called Dashboard in navigation, settings and help. Its
  address is unchanged. Calendar-day wording such as "Today" and "due today" is unchanged.
- **Phones show icon-only navigation.** The top-bar tabs and the four bottom destinations are 44 px
  icon tiles. Their text names stay available to screen readers.
- **Classic sidebar layout** keeps its toolbar with the scope and Add. Its settings shortcut is removed,
  as in the Guide layout.

## Upgrade

After publication use `ghcr.io/crimsonclyde/vergissmeinnicht:0.11.6` on linux/amd64 or linux/arm64.

This release adds **no database migration**. No new dependency, credential, service, environment
variable or outbound host. The Unraid template points to this release.

Verify a full server backup including original files first; retain the data mount and secrets.

The release workflow publishes stable tags as `0.11.6`, `0.11` and `latest`. Publication remains
separate from live deployment.

## Known limits

- At 320 px the Workspace name is truncated.
- On phones the top-bar tabs and bottom destinations show icons only. Sighted users lose the text labels
  for these four destinations.
- The Clock card is off by default, so a fresh account shows no time in the top bar until it is turned on.
- The Dashboard rename covers user-facing labels. URLs (for example `/w/:id` and `/account/today`) and
  code names keep "today".
- Physical phones and real screen readers have not been tested.
