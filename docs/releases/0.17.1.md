# 0.17.1

Owner release **78**, following 0.17.0 (77).

- **The top bar stays on every page** in Tokyo Nights and Galactic Guide. Clock and Weather are ordinary pages with the top bar (and the bottom bar on phones). Editors (Procedure builder, Journal, new Document) keep the bar; it scrolls away so the editor's own bar stays on top. During a run on a phone, the bar keeps its tools and time.
- **Weather opens The Daily Planet's weather.** The weather in the top bar and the Dashboard weather tile open today's edition and jump straight to its weather section, unfolded for that visit. Tapping again on the same page jumps back without a new history entry.
- Light, Memento Mori, Witch Forest and Places keep the sidebar and are unchanged.

No new migration (schema stays 0085). No API or data change.
The container image is `ghcr.io/crimsonclyde/vergissmeinnicht:0.17.1`.
Live deployment is separate from this release.
