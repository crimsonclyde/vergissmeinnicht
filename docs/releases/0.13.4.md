# 0.13.4

Owner release **59**, following 0.13.3 (58).

- ChatGPT can pass an available JPEG or PNG file to VMN for a Recipe photo or a Shopping
  or To-do List cover. The new tools use the existing Recipe and List cover permissions.
- VMN preserves the original bytes and creates its usual thumbnail and preview. The
  existing base64 upload and picker paths are available. An upload retry can recover
  the same attachment reference without another download.
- Recipe imports can request `requireImage: true` so VMN saves a new Recipe only when
  its cover refers to a valid uploaded image.

After upgrading, refresh the VMN tools in ChatGPT and open a fresh chat. Test a directly
attached JPEG or PNG first. A photograph extracted from a PDF must be made available as
a separate file by ChatGPT. That end-to-end hosted workflow still needs verification.
The server fetches file references only from `files.oaiusercontent.com`.
[Setup and usage](../admin/mcp.md#upload-an-image-already-available-in-chatgpt)

This patch introduces no database migration. Use
`ghcr.io/crimsonclyde/vergissmeinnicht:0.13.4` in the Unraid Repository field.

The signed Docker image is available for Linux amd64 and arm64. Upgrade
verification passed with six populated predecessor images, including 0.13.3.
