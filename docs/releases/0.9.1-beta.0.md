# 0.9.1-beta.0 — Celestial

The 43rd owner-counted release: a standalone refinement of the existing Moon card, available across every theme. Release 42 — The Curtain Between Worlds — and its Halloween dedication remain in the project history.

## What's changed

- **Celestial:** equal Sun and Moon centrepieces, delicate gold orbits, a dark instrument surface and silver-blue moonlight, following the approved Eclipse reference.
- **Both horizons:** actual sunrise, sunset, moonrise and moonset for the existing shared Workspace location. Lunar phase and illumination come from the existing local astronomy library; the illustration follows the real illuminated fraction and waxing/waning direction.
- **Comfortable on phones:** bodies stay side by side, with two compact information columns below. Wide cards place readings to either side. No new application theme.
- **Same settings:** existing tool enablement, saved Today choices and location behavior remain. No personal Weather fallback, geolocation, provider connection or new dependency. Days without events and missing locations are explicit; events follow the configured civil date/time zone, including moonset before moonrise. Next-full date uses that zone too.

## Upgrade

Image: `ghcr.io/crimsonclyde/vergissmeinnicht:0.9.1-beta.0` for linux/amd64 and linux/arm64. This beta does not move `latest`. Pin the exact version. Back up database and file storage before upgrading. No new migration: the schema remains at **61 migrations (0000–0060)**, the same as v0.9.0-beta.0. No new environment variable, service or credential. This release does not update a running installation automatically.

## Validation and limits

Local lint, typecheck and production build pass; **201 test files / 1,545 tests** pass, including existing Workspace/tool authorization negatives. Dedicated desktop and touch-mobile browser checks cover six themes at 320, 390, 768 and 1440 px, no overflow, axe accessibility, reduced motion and forced colours. Full release browser and native image/upgrade results are recorded in the execution ledger after completion.

Astronomy values are calculated estimates from the existing pinned SunCalc library, with the standard apparent solar horizon; the static vector surfaces are artistic rather than photographic maps. Physical devices, real screen readers and modest-device performance have not been certified. The existing large JavaScript chunk build warning remains.
