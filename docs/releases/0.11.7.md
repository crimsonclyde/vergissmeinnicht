# 0.11.7

Owner-counted release **52**, following published 0.11.6 (51). Release 42 — The Curtain Between
Worlds — and its Halloween dedication remain unchanged.

## Changes

- **Clock/Weather matches Celestial.** Both cards share the same theme-aware background and personal
  opacity setting. Transparent artwork replaces the old navy rectangles; labels, pictures and readings
  have their own space on phones and desktops. Text, pictures and controls stay opaque.
- **Weather artwork follows the forecast.** Clear skies, rain/drizzle/showers, snow/sleet and thunder
  use matching sun, rain, snow and storm illustrations. Other/unknown conditions retain their truthful
  native symbol. The condition is also written; a daily outlook is labelled when current data is absent.
- **Personal appearance belongs in Profile.** Pick a Workspace under Appearance for your theme,
  navigation layout, card styling and Workspace-weather location opt-in. The former Workspace Look
  page is removed. Other members keep their own settings. Shared Workspace location remains admin-managed;
  provider, units, model, credentials and fallback place remain personal account-wide Weather settings.
- **A simpler Appearance page.** Compact theme previews, icon actions and optional info disclosures
  replace repeated paragraphs. Save, Cancel, Reset and the default star keep accessible names and
  48px targets. Phones use a two-column theme grid and compact icon controls.
- **Weather refreshes after changing its Workspace-location opt-in.** The toggle is disabled while
  saving and a successful save refreshes the existing forecast and atmosphere.

## Upgrade

Use `ghcr.io/crimsonclyde/vergissmeinnicht:0.11.7` on linux/amd64 or linux/arm64 after publication.
The Unraid template points to this version. Verify a full server backup, including original files,
and retain the data mount and secrets before upgrading.

No database migration, dependency, service, credential type, environment variable or outbound host is
added. Existing preferences and Workspace data are preserved. Stable publication moves `0.11` and
`latest`; publication is separate from live deployment.

## Validation

Local checks and published workflow evidence are recorded in `docs/development/steps.md` (27.5–27.8
and the owner release 52 record). The release workflow requires quality/browser checks, both native
container builds and smoke tests, vulnerability scans, keyless signing, SBOM and verification of the
exact published image, including populated upgrades from 0.11.6 and the retained older predecessors.
Browser flows run sequentially to respect the existing request limits during the expanded opacity
matrix; production and test request limits are unchanged.

## Known limits

- Cloudy, partly cloudy, foggy and unknown conditions use native symbols until matching paintings exist.
- The normalized forecast has no day/night flag; the paintings represent the supplied condition only.
- Very transparent cards over a bright personal photo may need a stronger chosen background tint.
- Icon controls retain accessible names/tooltips; some descriptions are now available only on request.
- Physical phones and real screen readers have not been tested. Existing build chunk-size warnings remain.
