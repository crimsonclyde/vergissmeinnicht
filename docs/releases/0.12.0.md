# 0.12.0

Owner-counted release **54**, following 0.11.8 (53). Release 42 — The Curtain Between Worlds —
and its Halloween dedication remain unchanged.

## Changes

- OAuth discovery now advertises the exact same issuer in both metadata documents, including its
  root trailing slash. This removes a protocol inconsistency when connecting an MCP client.
- Added 29 OAuth protocol/security tests covering discovery, public registration, authorization,
  PKCE, resource binding, refresh rotation/replay/expiry, consent/MFA and secret redaction.
- Extended desktop and phone browser coverage through password and TOTP back to pending consent,
  decline, explicit Workspace selection, renewed consent and revocation.
- Documented the same-origin private Tailscale HTTPS configuration for released OpenAI
  tunnel-client v0.0.19, with Docker assumptions, isolated testing gates and rollback guidance.

## Upgrade

After publication, use `ghcr.io/crimsonclyde/vergissmeinnicht:0.12.0` on linux/amd64 or linux/arm64.
The repository's Unraid template points to this version; no running Unraid installation is changed.
Verify a full server backup, including originals, and retain the data mount and secrets before upgrading.
Stable publication moves `0.12` and `latest`; existing `0.11` images remain available.

No migration, dependency, environment variable, credential, permission or new outbound destination
is added. `PUBLIC_ORIGIN`, browser authorization, exact `/mcp` resource binding, existing grants,
PKCE, MFA and current Workspace authorization remain unchanged. MCP stays optional/off by default.
No tunnel, external account or credential is created, and no port is exposed by this release.

## Validation

All **212 unit/security files / 1,644 tests** were verified locally across the full run and the
permission-corrected rerun of four existing files; sandbox restrictions initially blocked local
socket/CLI fixtures. Lint, full typechecks, dependency audit (no known vulnerabilities), production
build and the targeted desktop/phone browser scenarios passed. Full browser and native release gates
must pass before publication; final results are recorded in the development ledger.

The release workflow builds/smoke-tests/scans both native architectures, signs the multi-architecture
image with a CycloneDX SBOM, verifies the exact published version/revision and runs populated upgrades
from independently verified 0.11.8 and the retained older published/candidate predecessors.

## Known limits

- Live ChatGPT/Secure MCP Tunnel integration remains untested: actual hosted DCR/shim behavior,
  canonical issuer/resource round trip, refresh/revocation and container tailnet routing still need
  a separately approved isolated test. Local protocol tests do not certify that deployment.
- Docker hardening/file permissions are source-reviewed assumptions, not observed Unraid results.
  The documented configuration targets v0.0.19; unreleased separate-origin forwarding is excluded.
- Physical phones, real screen readers and the existing large build chunks remain validation limits.
- Live deployment remains separate from release publication.
