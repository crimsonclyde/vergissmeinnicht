# 0.13.5

Owner release **60**, following 0.13.4 (59).

VMN now reports which stage failed when ChatGPT tries to upload a Recipe photo
or a List cover. Missing or invalid file objects, malformed URLs, unsupported
origins, unavailable links and download failures have separate codes. Responses
contain no signed URLs or local paths. File-host restrictions and permissions
stay in force.

After upgrading, open a fresh ChatGPT chat and attach a JPEG or PNG. Use
`upload_recipe_image_file` with `recipeId: null` and skip recipe creation during
the diagnostic. If the upload fails, report the exact code. The hosted handoff
for directly attached images and photos extracted from PDFs still needs
verification. [Setup and usage](../admin/mcp.md#upload-an-image-already-available-in-chatgpt)

This patch introduces no database migration. Use
`ghcr.io/crimsonclyde/vergissmeinnicht:0.13.5` in the Unraid Repository field.

The signed Docker image is available for Linux amd64 and arm64. Upgrade
verification passed with seven populated predecessor images, including 0.13.4.
