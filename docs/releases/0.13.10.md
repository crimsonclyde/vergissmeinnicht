# 0.13.10

Owner release **64**, following 0.13.8 (63).

- New Recipes default to **Public** in the authenticated shared cookbook, including
  ChatGPT-created Recipes. Users can choose **Private**. Existing private Recipes
  and legacy records retain their visibility.
- ChatGPT creates its own recipe image or extracts the original cookbook photo,
  then uses the shared native file upload. Regional ChatGPT image-download hosts
  are supported with bounded downloads and the existing security checks.
- Updated MCP instructions and schemas guide upload, required-cover save and
  readback. The separate optional VMN image generator is no longer suggested for
  these ChatGPT workflows; its errors also distinguish configuration and limits.
- The Guide picker is more compact. Recipe shopping can add all ingredients with
  serving scaling, preserves descriptive amounts, and supports an unknown base
  serving count. Management pages consistently use Memento Mori.
- The Places opacity preview remains responsive inside Memento Mori settings.
- The tunnel runbook explains how to persist VMN's shared Docker network through
  Unraid recreations.

No database migration. Existing content and visibility are preserved. Backups
containing unknown Recipe serving counts require 0.13.10 or later to restore.
Public Recipes are shared with signed-in VMN users through enabled Recipe
Workspaces, not published anonymously on the internet.

Use `ghcr.io/crimsonclyde/vergissmeinnicht:0.13.10` in the Unraid Repository field.
Keep the saved network shared with the MCP tunnel. Refresh VMN's connected tools
in ChatGPT after deployment to load the new instructions and privacy field.

The generated-image workflow was verified live through ChatGPT upload, Recipe
creation and independent cover readback. The cookbook original-photo flow remains
covered by its hosted import, readback and byte-preserving regression tests.

Validation: 1,717 tests across 214 files; 30 browser tests passed (2 skipped);
lint, typecheck, dependency audit, both native image smoke/security checks and
eleven populated upgrade checks passed. The workflow signed the multi-architecture
image and attached its CycloneDX SBOM.
