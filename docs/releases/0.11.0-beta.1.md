# 0.11.0-beta.1 — A Moment in Time

Owner-counted release **46**, following published v0.10.1-beta.0 (45). Earlier v0.11.0-beta.0 was a fully
built candidate held as an unpublished GitHub draft for owner review; its tag/image are preserved.
Release 42 — The Curtain Between Worlds — and its Halloween dedication remain unchanged.

## Changes

- One illustrated Clock/Weather card, with equal halves and each whole picture opening its dedicated
  screen. No text-link footer. Live clock hands agree with digital device time. A single chosen usable
  instrument fills the card; with neither chosen, it disappears.
- Chosen Clock/Weather comes first, followed by Celestial and the continuation card. Profile → Today
  keeps independent personal choices. Among these three, only Celestial defaults on, when the Workspace
  enables it. Existing personal/server gates remain; no new Workspace Clock/Weather switches.
- Dedicated Clock and Weather screens with Back and the shared 48px icon action bar. Clock includes
  local Stopwatch/laps and bounded Timer, with explicit Start/Pause/Resume/Reset. Timing remains in the
  signed-in tab during navigation; reload/sign-out/close resets it. No sound or background-alarm promise.
- Home in the Notes/private Journal phone action bar and desktop actions returns to the current Today
  screen. Unsaved-work confirmation and busy-save protection remain; Home never saves or awards success.
- Shared account/Workspace-scoped Weather requests, explicit missing/stale/source/fallback labels and
  detailed forecasts. Tomorrow, rain and wind remain on the Weather screen; the setting now says
  “Show tomorrow in Weather”. Pictures are decorative and never a substitute for actual readings.
- Updated README features and actual Space Guide/Memento Mori browser captures with fictional studio
  data and intercepted sample Weather. Original locally bundled artwork; no new external asset requests.

## Upgrade

After publication use `ghcr.io/crimsonclyde/vergissmeinnicht:0.11.0-beta.1` on linux/amd64 or linux/arm64.
This beta publishes only its exact version, never moves `latest`. Verify a full server backup including
original files first; retain data mount and secrets. No new migration, dependency, credential, service
or environment variable. The release workflow checks populated upgrades from the published
v0.10.1-beta.0 and the withheld v0.11.0-beta.0 candidate. The Unraid template points to this beta.
Publication remains separate from live deployment.
