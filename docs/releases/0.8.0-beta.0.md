# 0.8.0-beta.0 — Bring, everyday themes & security updates

## What's new

- **Bring:** keep track of things to take between homes, flats or other places, with optional from/to, due date, assignee and notes. Complete or cancel items, keep history, and undo actions. Relevant items appear on Today. Enable Bring under Workspace settings → Plugins; it starts off.
- **Everyday themes:** refreshed **Don't go into the (light)** and **Memento Mori (dark)**, with restrained original line art. System follows this pair; existing saved Dark preferences remain supported.
- **README:** clearer introduction and a fresh gallery of 16 screenshots using fictional demo data.
- **Dependency patches:** updated authentication, Fastify, Nodemailer and supporting dependencies. The recorded advisory review reduced 22 findings to zero known advisories; no suppressions were added. Audit results are time-sensitive.

## Upgrade

Back up the database **and file storage** before updating. Migration **0059_bring** brings the schema to 60 migrations. On Unraid, keep **Migrate on start** enabled. Existing settings, points, history and tool flags remain. No new environment variables or services. Older binaries refuse the upgraded database; rollback requires the pre-upgrade backup.
