# 0.10.1-beta.0 — Within Reach

Owner-counted release **45**, following v0.10.0-beta.0 (44). Release 42 — The Curtain Between Worlds —
and its Halloween dedication remain unchanged in project history.

## Changes

- Focused phone entry screens for Notes, personal Journal, Procedures, Recipes, Reminders/scheduling,
  Documents, Equipment, Maintenance, Contacts and Bring. Lists keeps quick inline item addition with
  matching compact editing dialogs.
- Shared icon-based bottom actions, accessible names, 48px targets, progress, Back/Next, explicit Save,
  unsaved-change protection, keyboard/safe-area clearance and preserved input during resizing.
- Clearer visual writing controls in Notes/Journal; unsupported Markdown remains intact through phone
  editing. Existing scoped original uploads, private Journal boundaries and server-confirmed rewards remain.
- Node 24.22.2 production base and development floor, with the reviewed Brotli/DNS/TLS security fixes;
  the affected minimatch 10 dependency chain moves to 11.0.1.

## Upgrade

Use `ghcr.io/crimsonclyde/vergissmeinnicht:0.10.1-beta.0` after publication, on linux/amd64 or linux/arm64.
This beta publishes its exact version and does not move `latest`. Verify a full server backup including
original files first. Keep the existing data mount and secrets. No new database migration, service,
credential or environment variable. The release workflow checks a populated upgrade from the exact
published v0.10.0-beta.0 digest. The Unraid template points to this beta; existing installations are
updated by their operator. No live deployment is performed by publication.

## Validation and limits

Implementation CI passed quality, browser and both native container build/smoke/vulnerability checks.
Local validation passed lint, typecheck, production web/container build and container smoke, 208 test
files / 1,580 tests, all account and Guide browser flows, plus the theme/smoke tests. Phone checks include
320px, light/dark accessibility, Back/Next, failed Save/retry, cancellation and breakpoint changes.

Physical iPhone/Android keyboards and screen readers still need review. Specialized import/export,
bulk, destructive and settings dialogs retain their existing layouts. Existing large JavaScript chunk
warnings remain. AI client/tunnel setup and the separate dependency-bump PRs are not part of this release.
