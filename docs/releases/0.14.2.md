# 0.14.2

Owner release **69**, following 0.14.1 (68).

- **Recipe photos cropped out of a PDF upload again.** ChatGPT stores those
  images on its Denmark East storage host, which VMN now accepts.
- **New ChatGPT file hosts without an update:** when ChatGPT uses a storage
  host VMN does not know yet, it appears under Server admin → AI connections →
  **File sources**. Tap the check icon and the next try works, with no restart.
  The bin icon removes a host again. Only exact host names VMN refused itself
  can be allowed.
- **Fixed:** the ChatGPT upload tools ignored the optional container variable
  `MCP_CHATGPT_FILE_HOSTS`. It now works as documented.

Database migration 0076 (ChatGPT file hosts) runs on start. No required new
environment variable. Existing content is preserved.

Use `ghcr.io/crimsonclyde/vergissmeinnicht:0.14.2` in the Unraid Repository
field. Refresh VMN's connected tools in ChatGPT after deployment.

Live deployment remains separate.
