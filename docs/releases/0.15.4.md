# 0.15.4

Planned owner release **74**, following 0.15.3 (73).

- The Daily Planet card on the Dashboard shares its issue’s masthead artwork,
  saved crop and Newsflash. Select the masthead to open that issue. Configured
  Dashboard headlines are shown when an issue has no summary.
- Gazette Weather aligns the labeled temperature chart with the daily columns
  on desktop and uses compact day rows on phones. Open a day’s forecast details
  for model notes and ranges. Dotted underlines mark lower-confidence days.

There are no new database migrations, environment variables or MCP permission
scopes. Use `ghcr.io/crimsonclyde/vergissmeinnicht:0.15.4` in Unraid.
