# Galactic Guide artwork

The bundled original transparent illustrations come from the owner-reviewed Release 42 prototype. Source prompts and generated filenames are recorded in `docs/design/release-42/directions/constellation-floating-prompts.json` and `full-guide-object-prompts.json`; the unchanged reference PNG is documentation only.

Tool images are local WebP cutouts, 54–124 KB each. The 7.2 KB space backdrop is the compressed background embedded in the reviewed prototype, extracted without regeneration. No external runtime source, image API, executable plugin or upload is introduced. Decorative images have empty alternative text, do not capture input and load lazily; normal tool labels and stored procedure icons carry meaning. Space is opt-in. Other themes never render these cutouts; No image removes them and the Space scene. Forced colors removes decoration. Background opacity never fades text or controls.

The fireplace depicts chimney-themed procedures; a general guidebook is used otherwise. The supermarket stands for Lists and the Tesla coil for Equipment, without inventing utility monitoring. Water/plant-themed procedures use the water pump; the Reminders tool uses the alarm clock rather than asserting that every reminder concerns watering plants.
