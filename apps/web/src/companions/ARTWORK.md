# Celebration companions

Created 2026-10-25 with the built-in imagegen tool from three owner-supplied character reference images. The owner requested simplified versions and random selection for the existing progress toast.

- **Herr Fuchsky:** fox; reference `ChatGPT Image Jul 10, 2026, 01_04_58 PM.png`.
- **Count Duckula:** vampire duck; reference `ChatGPT Image Jul 10, 2026, 01_09_49 PM.png`. Yellow deliberately softened.
- **Fester Fiesta:** duck with sombrero; reference `ChatGPT Image Jul 10, 2026, 01_10_44 PM.png`.

References remain outside the repository. Generated transparent illustrations are resized to 256px WebP for the bundled 72px toast. They are static local assets; no runtime image generation, remote asset or user upload route. Names appear as ordinary text; images have empty alt text to avoid repeating the name in the live status. Random selection is presentation-only, independent of points.

The owner revised the ducks: remove feet, retain Count Duckula's closed cloak, smaller eyes and reserved vegetarian-vampire expression from the photo; dress Fester Fiesta in a Mexican charro jacket. `count-duckula-v2.webp` and `fester-fiesta-v2.webp` are the shipped versions; first drafts remain in the generation output directory outside the repository.
